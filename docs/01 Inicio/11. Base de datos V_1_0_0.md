# Documento 06: Diseño e Ingeniería de Base de Datos

## Modelo Conceptual (Entidad-Relación)
El modelo conceptual identifica las entidades centrales del dominio de EcoLogCity:
- **Usuario:** Actores que interactúan con el sistema.
- **Vehículo:** Unidades de la flota con capacidades y factores de emisión.
- **Pedido (Order):** Requerimiento logístico con geolocalización y ventana horaria.
- **Ruta:** Agrupación optimizada de pedidos asignada a un vehículo.

## Modelo Lógico (Nivel 3FN)
1. **Usuarios:** `id` (PK, UUID), nombre_completo, email (UNIQUE), password_hash (scrypt), rol (`ADMIN` / `USUARIO`), activo, created_at.
2. **Vehiculos:** `id` (PK, UUID), placa (UNIQUE), marca, modelo, tipo_vehiculo, capacidad_peso_kg, capacidad_volumen_m3, consumo_gal_km, tipo_combustible, activo, created_at.
3. **Pedidos:** `id` (PK, UUID), codigo_seguimiento, cliente_nombre, cliente_telefono, cliente_email, direccion_texto, distrito, referencia, latitud, longitud, peso_kg, volumen_m3, ventana_inicio, ventana_fin, tiempo_servicio_min, prioridad, estado, usuario_id (FK -> usuarios.id), created_at.
4. **Zonas_Cobertura:** `id` (PK, SERIAL), nombre (UNIQUE), codigo_postal, lat_min, lat_max, lon_min, lon_max, activo, created_at.
5. **Rutas:** `ruta_id` (PK, UUID), vehiculo_id (FK), fecha_ejecucion, distancia_total, co2_estimado, estado.
6. **Ruta_Paradas:** `parada_id` (PK, UUID), ruta_id (FK), pedido_id (FK), secuencia_orden, eta_estimado.

## Modelo Físico (DDL SQL) e Índices

```sql
-- Extensión requerida para UUID
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
-- Extensión requerida para datos geoespaciales
CREATE EXTENSION IF NOT EXISTS "postgis";

-- Tabla Usuarios (US-007 / RBAC)
CREATE TABLE IF NOT EXISTS usuarios (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    nombre_completo VARCHAR(150) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    password_hash TEXT NOT NULL, -- scrypt: salt:hash (hex)
    rol VARCHAR(20) NOT NULL DEFAULT 'USUARIO' CHECK (rol IN ('ADMIN', 'USUARIO')),
    activo BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX IF NOT EXISTS idx_usuarios_email ON usuarios(LOWER(email));

-- Tabla Vehículos
CREATE TABLE IF NOT EXISTS vehiculos (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    placa VARCHAR(10) UNIQUE NOT NULL,
    marca VARCHAR(50),
    modelo VARCHAR(50),
    tipo_vehiculo VARCHAR(30) DEFAULT 'FURGON_MEDIANO',
    capacidad_peso_kg NUMERIC(10, 2) NOT NULL DEFAULT 1500.00,
    capacidad_volumen_m3 NUMERIC(10, 3) NOT NULL DEFAULT 12.00,
    consumo_gal_km NUMERIC(6, 4) NOT NULL DEFAULT 0.12,
    tipo_combustible VARCHAR(20) DEFAULT 'DIESEL',
    activo BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Tabla Pedidos
CREATE TABLE IF NOT EXISTS pedidos (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    codigo_seguimiento VARCHAR(50) UNIQUE NOT NULL,
    cliente_nombre VARCHAR(150) NOT NULL,
    cliente_telefono VARCHAR(20),
    cliente_email VARCHAR(100),
    direccion_texto TEXT NOT NULL,
    distrito VARCHAR(100) NOT NULL,
    referencia TEXT,
    latitud DOUBLE PRECISION NOT NULL,
    longitud DOUBLE PRECISION NOT NULL,
    peso_kg NUMERIC(10, 2) NOT NULL DEFAULT 1.00 CHECK (peso_kg > 0),
    volumen_m3 NUMERIC(10, 3) NOT NULL DEFAULT 0.05 CHECK (volumen_m3 > 0),
    ventana_inicio TIME NOT NULL,
    ventana_fin TIME NOT NULL,
    tiempo_servicio_min INT NOT NULL DEFAULT 10 CHECK (tiempo_servicio_min > 0),
    prioridad INT NOT NULL DEFAULT 1 CHECK (prioridad BETWEEN 1 AND 5),
    estado VARCHAR(30) NOT NULL DEFAULT 'REGISTRADO' 
        CHECK (estado IN ('REGISTRADO', 'PLANIFICADO', 'EN_RUTA', 'ENTREGADO', 'CANCELADO')),
    observaciones TEXT,
    usuario_id UUID REFERENCES usuarios(id) ON DELETE SET NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT check_ventanas_horarias CHECK (ventana_fin > ventana_inicio)
);
CREATE INDEX IF NOT EXISTS idx_pedidos_estado ON pedidos(estado);
CREATE INDEX IF NOT EXISTS idx_pedidos_distrito ON pedidos(distrito);
CREATE INDEX IF NOT EXISTS idx_pedidos_lat_lon ON pedidos(latitud, longitud);
CREATE INDEX IF NOT EXISTS idx_pedidos_usuario ON pedidos(usuario_id);

-- Tabla Rutas
CREATE TABLE IF NOT EXISTS rutas (
    ruta_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    vehiculo_id UUID REFERENCES vehiculos(id),
    fecha_ejecucion DATE NOT NULL,
    distancia_total_km DECIMAL(10,2),
    co2_estimado_kg DECIMAL(10,2),
    estado VARCHAR(50) NOT NULL DEFAULT 'PLANIFICADA'
);

-- Tabla Intermedia (Paradas)
CREATE TABLE IF NOT EXISTS ruta_paradas (
    parada_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    ruta_id UUID REFERENCES rutas(ruta_id) ON DELETE CASCADE,
    pedido_id UUID REFERENCES pedidos(id),
    secuencia_orden INTEGER NOT NULL,
    eta_estimado TIMESTAMP WITH TIME ZONE
);
CREATE INDEX IF NOT EXISTS idx_ruta_paradas_ruta ON ruta_paradas(ruta_id);
```
