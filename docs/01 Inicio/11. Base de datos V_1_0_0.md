# Documento 06: Diseño e Ingeniería de Base de Datos

## Modelo Conceptual (Entidad-Relación)
El modelo conceptual identifica las entidades centrales del dominio de EcoLogCity:
- **Usuario:** Actores que interactúan con el sistema.
- **Vehículo:** Unidades de la flota con capacidades y factores de emisión.
- **Pedido (Order):** Requerimiento logístico con geolocalización y ventana horaria.
- **Ruta:** Agrupación optimizada de pedidos asignada a un vehículo.

## Modelo Lógico (Nivel 3FN)
1. **Usuarios:** `usuario_id` (PK), email, password, rol_id (FK), estado.
2. **Vehiculos:** `vehiculo_id` (PK), placa, capacidad_kg, factor_emision, activo.
3. **Pedidos:** `pedido_id` (PK), cliente_nombre, direccion, latitud, longitud, peso_kg, ventana_inicio, ventana_fin, estado, usuario_id (FK).
4. **Rutas:** `ruta_id` (PK), vehiculo_id (FK), fecha_ejecucion, distancia_total, co2_estimado, estado.
5. **Ruta_Paradas:** `parada_id` (PK), ruta_id (FK), pedido_id (FK), secuencia_orden, eta_estimado.

## Modelo Físico (DDL SQL) e Índices

```sql
-- Extensión requerida para UUID
CREATE EXTENSION IF NOT EXISTS "pgcrypto";
-- Extensión requerida para datos geoespaciales
CREATE EXTENSION IF NOT EXISTS "postgis";

-- Tabla Usuarios
CREATE TABLE usuarios (
    usuario_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email VARCHAR(255) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    rol VARCHAR(50) NOT NULL DEFAULT 'CONDUCTOR',
    estado VARCHAR(20) NOT NULL DEFAULT 'ACTIVO',
    creado_en TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_usuarios_email ON usuarios(email);

-- Tabla Vehículos
CREATE TABLE vehiculos (
    vehiculo_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    placa VARCHAR(15) NOT NULL UNIQUE,
    capacidad_kg DECIMAL(10,2) NOT NULL,
    factor_emision_base DECIMAL(10,4) NOT NULL, -- gr de CO2 por km
    activo BOOLEAN DEFAULT TRUE
);

-- Tabla Pedidos
CREATE TABLE pedidos (
    pedido_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    cliente_nombre VARCHAR(255) NOT NULL,
    direccion_texto TEXT NOT NULL,
    coordenadas GEOMETRY(Point, 4326) NOT NULL,
    peso_kg DECIMAL(10,2) NOT NULL,
    ventana_inicio TIME NOT NULL,
    ventana_fin TIME NOT NULL,
    estado VARCHAR(50) NOT NULL DEFAULT 'PENDIENTE',
    creado_en TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_pedidos_estado ON pedidos(estado);

-- Tabla Rutas
CREATE TABLE rutas (
    ruta_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    vehiculo_id UUID REFERENCES vehiculos(vehiculo_id),
    fecha_ejecucion DATE NOT NULL,
    distancia_total_km DECIMAL(10,2),
    co2_estimado_kg DECIMAL(10,2),
    estado VARCHAR(50) NOT NULL DEFAULT 'PLANIFICADA'
);

-- Tabla Intermedia (Paradas)
CREATE TABLE ruta_paradas (
    parada_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    ruta_id UUID REFERENCES rutas(ruta_id) ON DELETE CASCADE,
    pedido_id UUID REFERENCES pedidos(pedido_id),
    secuencia_orden INTEGER NOT NULL,
    eta_estimado TIMESTAMP WITH TIME ZONE
);
CREATE INDEX idx_ruta_paradas_ruta ON ruta_paradas(ruta_id);
```
