# Documento 02: Requisitos No Funcionales (RNF)

A continuación, se definen los atributos de calidad del sistema EcoLogCity, basándose en la norma ISO/IEC 25010 y utilizando escenarios de calidad con métricas SMART (Específicas, Medibles, Alcanzables, Relevantes y Temporales).

| ID | Categoría ISO 25010 | Escenario de Calidad (Fuente -> Estímulo -> Entorno -> Artefacto -> Respuesta -> Medida SLA) |
| :--- | :--- | :--- |
| **RNF-001** | Rendimiento (Eficiencia de Desempeño) | **Fuente:** Algoritmo Metaheurístico.<br>**Estímulo:** Petición de generación de ruta óptima para 100 pedidos y 5 vehículos.<br>**Entorno:** Operación en inicio de jornada (alta carga de CPU).<br>**Artefacto:** Motor Metaheurístico y API Backend.<br>**Respuesta:** Procesar las restricciones (VRPTW, Green VRP, Altitud) y retornar la matriz de rutas óptimas.<br>**Medida:** Tiempo de procesamiento ≤ 45 segundos en el 90% de las ejecuciones. |
| **RNF-002** | Seguridad | **Fuente:** Atacante externo / Tráfico malicioso.<br>**Estímulo:** Intento de inyección SQL o acceso indebido a endpoints de geolocalización.<br>**Entorno:** Producción.<br>**Artefacto:** API Gateway / Módulo de Autenticación JWT.<br>**Respuesta:** Bloquear petición, registrar evento de auditoría y rechazar acceso no firmado.<br>**Medida:** 0% de vulnerabilidades críticas OWASP Top 10 explotables en auditorías de código. |
| **RNF-003** | Disponibilidad (Fiabilidad) | **Fuente:** Infraestructura cloud.<br>**Estímulo:** Caída temporal del servicio principal de Base de Datos.<br>**Entorno:** Operación logística 24/7.<br>**Artefacto:** Cluster de BD (PostgreSQL).<br>**Respuesta:** Failover automático hacia la base de datos réplica secundaria.<br>**Medida:** RTO ≤ 1 minuto, RPO ≤ 15 segundos, SLA de disponibilidad global ≥ 99.9% mensual. |
| **RNF-004** | Usabilidad | **Fuente:** Conductor de reparto.<br>**Estímulo:** Uso del Visor Cartográfico para visualizar la siguiente parada en condiciones de alta luminosidad (exteriores).<br>**Entorno:** Operación en campo a plena luz del día.<br>**Artefacto:** Frontend (React.js Web App).<br>**Respuesta:** Despliegue de interfaz con alto contraste y botones de fácil acceso.<br>**Medida:** Índice de contraste mínimo de 4.5:1 (WCAG AA) y tiempo de aprendizaje menor a 15 minutos para flujo principal. |
| **RNF-005** | Precisión Funcional | **Fuente:** Componente de Sostenibilidad.<br>**Estímulo:** Petición para calcular la huella de CO₂ post-ruta.<br>**Entorno:** Cierre de jornada.<br>**Artefacto:** Calculador de Huella de CO₂ (Backend).<br>**Respuesta:** Calcular la emisión aplicando el factor de corrección por altitud (3,250 msnm).<br>**Medida:** Tasa de error en el cálculo volumétrico respecto a la norma GHG Protocol ≤ 2%. |
