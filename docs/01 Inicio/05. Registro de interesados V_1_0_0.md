## 3. Criterio Interno / Externo

Para este registro:

*Interno* = pertenece al equipo académico que ejecuta el proyecto.

*Externo* = se encuentra fuera del equipo, incluso cuando sea un actor de la empresa ficticia.

Esta definición evita clasificaciones ambiguas.
