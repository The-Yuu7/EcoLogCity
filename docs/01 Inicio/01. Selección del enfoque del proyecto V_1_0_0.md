## 2. Propósito

Determinar y justificar el enfoque de gestión y desarrollo más adecuado para el proyecto EcoLogCity, considerando las características del producto, la incertidumbre técnica, las condiciones académicas, la disponibilidad de interesados, las restricciones de calidad y la necesidad de desarrollar el producto mediante entregas incrementales.

La selección no se realiza únicamente por preferencia del equipo. Se utiliza una escala de ajuste de 1 a 5, donde los valores bajos favorecen un tratamiento predictivo y los valores altos incrementan la necesidad de adaptación.

---

## 3. Decisión de contextualización geográfica

### 3.1. Origen del caso académico

La consigna original define el proyecto “EcoLogística Lima” como un optimizador de rutas sostenibles para la empresa ficticia DistriRápido S.A.C.

### 3.2. Adaptación acordada por el equipo

El equipo adapta el caso a **Huancayo, Junín** bajo el nombre de **EcoLogCity**, por razones de viabilidad académica, proximidad territorial y mayor factibilidad para observar, validar y representar el contexto real del proyecto.

La modificación geográfica:

- no altera el problema de ingeniería principal;
- mantiene la empresa ficticia DistriRápido S.A.C.;
- mantiene VRPTW y Green VRP como núcleo técnico;
- conserva los requisitos funcionales y no funcionales de la consigna;
- sustituye únicamente las condiciones territoriales específicas de Lima por condiciones verificables de Huancayo;
- permite realizar validaciones con datos geográficos y actores locales más accesibles para el equipo.

### 3.3. Ámbito local adoptado

El PMV utilizará como ámbito principal de validación:

1. Huancayo Cercado;
2. El Tambo;
3. Chilca;
4. Pilcomayo;
5. San Agustín de Cajas.

Estos distritos participan en el ámbito de intervención del Plan de Movilidad Urbana Sostenible de Huancayo.

Como ejes viales críticos de referencia se consideran:

- calle Real;
- avenida Ferrocarril;
- avenida Huancavelica.

El diagnóstico del PMUS 2026 identifica estas vías entre aquellas de alta demanda y con problemas de congestión.

La actualización del Plan de Desarrollo Urbano de Huancayo aprobada en 2026 incorpora, además, cartografía de:

- red de transporte logístico;
- sistema vial primario;
- secciones del sistema vial.

Por tanto, el cambio de Lima a Huancayo cuenta con una base territorial verificable y no constituye una sustitución arbitraria de nombres.
