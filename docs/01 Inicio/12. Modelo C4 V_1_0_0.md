# Documento 07: Arquitectura de Software - Modelo C4

## Nivel 1: Diagrama de Contexto

El diagrama de contexto ilustra cómo los usuarios interactúan con EcoLogCity y cómo este se integra con los sistemas de terceros para cumplir su objetivo.

```mermaid
graph TD
    UserAdmin[Administrador/Operador Logístico] -->|Ingresa pedidos y planifica rutas| System[Sistema EcoLogCity]
    UserDriver[Conductor] -->|Visualiza rutas y actualiza entregas| System
    System -->|Carga de mapas base| OSM[OpenStreetMap API]
    System -->|Obtiene condiciones de tráfico real| Waze[Waze CCP API]
    System -->|Envía notificaciones de ETA| Mail[Servidor SMTP / Correo Cliente]
```

## Nivel 2: Diagrama de Contenedores

Este diagrama detalla los contenedores principales de la plataforma web.

```mermaid
graph TD
    subgraph Sistema EcoLogCity
        UI[Single Page Application - React] -->|HTTPS / REST| API[API Backend - Node/FastAPI]
        API -->|Lectura / Escritura de Datos| DB[(Base de Datos PostgreSQL + PostGIS)]
        API -->|Ejecución Intensiva| VRP[Motor Metaheurístico VRPTW]
    end
    
    User[Usuarios DistriRápido] -->|Acceso Web/Mobile| UI
```

## Nivel 3: Diagrama de Componentes

Detalle interno del contenedor principal (API Backend), mostrando la segregación de responsabilidades.

```mermaid
graph TD
    subgraph API Backend Contenedor
        Router[Router API / Endpoints]
        AuthMid[Middleware de Seguridad JWT]
        
        OrderCtrl[Controlador de Pedidos]
        RouteCtrl[Controlador de Rutas]
        DashCtrl[Controlador de Dashboard]
        
        OrderServ[Servicio de Pedidos]
        RouteServ[Servicio de Optimización y VRP]
        GeoServ[Servicio Geoespacial / Altitud]
        CarbonServ[Calculador de Emisiones CO2]
        
        Repo[(Repositorios TypeORM / SQLAlchemy)]
        
        Router --> AuthMid
        AuthMid --> OrderCtrl
        AuthMid --> RouteCtrl
        AuthMid --> DashCtrl
        
        OrderCtrl --> OrderServ
        RouteCtrl --> RouteServ
        DashCtrl --> CarbonServ
        
        RouteServ --> GeoServ
        RouteServ --> CarbonServ
        
        OrderServ --> Repo
        RouteServ --> Repo
        CarbonServ --> Repo
    end
```
